# My AI Library - Windows Beta 6

## Your local-first AI learning and research workspace

My AI Library turns videos, audio, PDFs, documents, notes, and research files into an organized, searchable knowledge workspace for Windows.

Keep original sources connected to transcripts, citations, timestamps, generated study material, and AI-assisted answers. Build separate local workspaces, study media without losing its context, and choose the AI providers and local tools that fit your workflow.

## What you can do

### Build a personal knowledge library

- Import videos, audio, PDFs, documents, notes, and research files.
- Organize material into folders, playlists, tabs, and separate storage workspaces.
- Process multiple resources in the background with visible progress and recovery information.
- Search across your library while keeping every result connected to its original source.

### Ask questions with source context

- Ask questions about one resource or your complete library.
- Follow source-aware citations and clickable timestamps back to the relevant media position.
- Continue long answers while preserving the conversation and completion state.
- Use Chat, Home Ask AI, Video Ask AI, and Audio Ask AI with the same response behavior.

### Study and review

- Generate summaries, chapters, subchapters, flashcards, quizzes, mind maps, and notes.
- Create Active Recall exercises and Self-Test questions.
- Watch and listen with transcripts, captions, starred moments, attachments, and media metrics.
- Configure local Whisper, Tesseract, and WtP/Canine tools from Settings.

## Improved in Beta 6

### Smoother, more reliable AI responses

- AI answers now type continuously through uneven provider delivery and paragraph boundaries.
- The animation adapts to incoming text instead of exhausting each provider chunk and visibly pausing.
- Markdown and words remain intact while the remaining response drains smoothly after completion.
- A complete answer is no longer incorrectly marked as interrupted when a provider finishes normally without sending a finish reason.
- Genuine transport or provider failures still preserve the partial answer and show the interruption notice.
- Completed historical messages do not replay their animation when reopened or rerendered.

### Packaged WtP/Canine support

- The Windows backend now includes the dynamically loaded compatibility modules used by WtP/SaT models.
- Existing valid model folders can be configured and tested without downloading the same model again.
- The packaged release gate downloads a temporary public `sat-3l` model, validates it through the production backend, performs sentence segmentation, and removes the temporary model afterward.

### Cleaner desktop lifecycle

- Starting a new My AI Library development or packaged session cleans up stale process trees owned by the same application.
- Cleanup is scoped to My AI Library processes and data paths; unrelated Electron, Python, Node.js, and backend processes are not terminated.
- Backend shutdown is awaited and includes a controlled process-tree fallback when graceful termination cannot finish.

### Refined application identity

- Beta 6 introduces the final frameless book mark across the Windows executable, installer, tray, splash, loading view, sidebar, and favicon.
- Windows icon and tray frames are generated from the same high-resolution source at sizes from 16 through 256 pixels.
- The book mark is centered, unclipped, and sized consistently for small Windows taskbar and tray surfaces.

### Workspace reliability

- Registered storage folders and existing-account workspace state are preserved consistently through schema initialization.
- Workspace creation, activation, protected-default behavior, deletion, and unrelated-file preservation remain covered by packaged validation.

## Privacy and storage

- Library databases, indexes, downloaded models, and generated workspace data remain in your selected local storage locations.
- Authentication refresh tokens are stored through Electron `safeStorage`, backed by Windows data protection when available.
- Firebase and GitHub credentials are never embedded as release secrets in the application.
- Configured cloud AI providers receive only the requests and context required for the features you choose to use.

## Installation and updates

1. Download `MyAI-Library-Setup-0.1.0-beta.6-x64.exe`.
2. Run the installer.
3. Because this beta is currently unsigned, Windows SmartScreen may show **Unknown Publisher**. Review the warning and choose **Run anyway** only if you trust the download.
4. Existing Beta 5 installations can discover Beta 6 from **Settings -> Updates** on the Testing channel.

The release also includes:

- `beta.yml` for Testing-channel update discovery.
- An installer blockmap for differential updates.
- `SHA256SUMS.txt` for installer verification.

## System requirements

- Windows 10 or Windows 11
- 64-bit processor
- Internet access for authentication, configured cloud AI providers, model downloads, and application updates
- Additional disk space and memory when using optional local AI models
