# MyAiLibrary — Windows Beta 5

Turn videos, audio, PDFs, documents, notes, and research into an organized, searchable learning workspace.

MyAiLibrary keeps your source material connected to AI-assisted search, citations, transcripts, media playback, generated study tools, and your own local folder structure.

## Build a personal research library

- Import and organize videos, audio, PDFs, documents, notes, and other learning resources.
- Group material into folders, playlists, and separate storage workspaces.
- Process resources in the background with visible status and recovery feedback.
- Search your library while keeping results connected to their original source.

## Ask, study, and review

- Ask questions about one resource or your complete library.
- Follow source-aware citations and clickable timestamps back to the exact media position.
- Generate summaries, chapters, subchapters, flashcards, quizzes, mind maps, notes, Active Recall exercises, and Self-Test questions.
- Watch or listen with transcripts, captions, starred moments, attachments, and media metrics.

## Safer workspace management

Beta 5 completes the Workspace Storage experience:

- Existing folders selected in Settings can now be registered reliably.
- Complete workspace drafts save correctly, with accurate success and error feedback.
- Secondary workspaces created from Settings can be permanently deleted after a clear confirmation.
- The original onboarding workspace is visibly marked as **Default** and cannot be deleted.
- Deleting an active secondary workspace automatically returns the application to the protected default workspace.
- Workspace records, resources, notes, generated content, conversations, diagnostics, and vector indexes are removed together.

MyAiLibrary distinguishes between two kinds of workspace folder:

- **App-created folder:** the application records an ownership marker and can remove the complete workspace folder during deletion.
- **Existing folder selected by you:** MyAiLibrary removes only its own tracked data and files. The selected root and unrelated personal files remain untouched.

Deletion that cannot finish—such as when another program has a file open—stays locked and can be retried safely.

## Desktop experience

- Detach supported pages into their own windows and attach them again.
- Keep multiple resources open with workspace tabs.
- Choose light, dark, or system appearance.
- Configure AI providers, models, integrations, diagnostics, storage, and updates.
- Use encrypted Windows-protected storage for persistent authentication refresh tokens.

## Beta notice

This is a public Windows beta intended for testing and early feedback.

The installer is currently unsigned, so Windows SmartScreen may display an **Unknown Publisher** warning. Windows code signing will be added in a future release.

Before testing beta software, keep a backup of important or irreplaceable files.

## System requirements

- Windows 10 or Windows 11
- 64-bit processor
- Internet access for account authentication, configured AI providers, and application updates

## Installation and updates

1. Download `MyAI-Library-Setup-0.1.0-beta.5-x64.exe`.
2. Run the installer.
3. If Windows SmartScreen appears, review the warning and choose **Run anyway** if you trust the download.
4. Existing beta installations can discover Beta 5 from **Settings → Updates** on the Testing channel.

The release also includes `beta.yml` for application updates, an installer blockmap for differential updates, and `SHA256SUMS.txt` for verification.
