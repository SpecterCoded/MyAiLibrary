# MyAiLibrary - Windows Beta 7

## Your local-first AI learning and research workspace

MyAiLibrary turns videos, audio, PDFs, documents, notes, and research files into an organized, searchable knowledge workspace for Windows.

Keep every answer connected to its source through citations, transcripts, timestamps, and media context. Build separate local workspaces, generate study material, and choose the cloud or local AI tools that fit the way you learn and research.

## What you can do

### Build a personal knowledge library

- Import videos, audio, PDFs, documents, notes, and research files.
- Organize material into folders, playlists, tabs, and separate storage workspaces.
- Process multiple resources in the background with visible progress and recovery information.
- Search across your library while keeping results connected to their original sources.

### Ask questions with source context

- Ask about one resource or your complete library.
- Follow source-aware citations and clickable timestamps to the relevant media position.
- Use Chat, Home Ask AI, Video Ask AI, and Audio Ask AI with consistent streaming and completion behavior.
- Continue long answers while preserving their text, sources, and response status.

### Study and review

- Generate summaries, chapters, subchapters, flashcards, quizzes, mind maps, and notes.
- Create Active Recall exercises and Self-Test questions.
- Watch and listen with transcripts, captions, starred moments, attachments, and media metrics.
- Configure local Whisper, Tesseract, and WtP/Canine tools from Settings.

## Improved in Beta 7

### Answers continue while you work

- Active AI generation now belongs to the application instead of the page that started it.
- You can navigate to another page, switch workspace tabs, minimize the window, hide MyAiLibrary to the tray, or work in another application without cancelling the answer.
- Chat, Home Ask AI, Video Ask AI, and Audio Ask AI restore the correct active or completed answer when you return.
- If an answer completed while hidden, it appears completed instead of replaying from the beginning.
- If generation is still active, the response catches up to its wall-clock position and continues smoothly.

Background generation continues only while MyAiLibrary remains running. Fully quitting or restarting the application intentionally ends active requests.

### Faster, smoother response animation

- The shared typewriter is faster and adapts continuously to the provider's delivery rate and available text reserve.
- Unicode graphemes, emoji, Markdown fragments, words, and paragraphs remain safe while text is revealed.
- Normal one-to-two-second provider gaps are buffered without abrupt animation jumps.
- Remaining text drains smoothly when generation finishes.
- Completed historical messages do not replay their animation.

### Clear cancellation behavior

- Navigation, window focus changes, tray hiding, and result-panel dismissal do not stop generation.
- **Stop Generation** cancels the request and preserves the partial answer.
- **Clear Conversation** removes the relevant task and conversation state.
- Logging out or quitting MyAiLibrary cancels and clears authenticated background tasks.
- Separate surfaces can generate independently while each conversation or resource keeps one active request.

### Composer and tray refinements

- The globe, attachment, and microphone controls now work on the first click, including when the composer begins collapsed.
- Pointer actions fire exactly once and keyboard activation remains available.
- The native Windows tray menu now contains the clearer **Open MyAiLibrary** and **Quit MyAiLibrary** actions.
- Left-clicking the tray icon still opens MyAiLibrary, and quitting uses the normal clean shutdown path.
- The application, shortcuts, splash screen, installer, and release title now consistently use the name **MyAiLibrary**.
- The Windows installer uses the native Segoe UI font for clear, dependable rendering.

## Privacy and storage

- Library databases, indexes, downloaded models, and generated workspace data remain in your selected local storage locations.
- Authentication refresh tokens are stored through Electron `safeStorage`, backed by Windows data protection when available.
- Firebase and GitHub credentials are never embedded as release secrets in the application.
- Configured cloud AI providers receive only the requests and context required for the features you choose to use.

## Installation and updates

### New installation

1. Download `MyAI-Library-Setup-0.1.0-beta.7-x64.exe`.
2. Run the installer.
3. This beta is currently unsigned, so Windows SmartScreen may show **Unknown Publisher**. Review the warning and choose **Run anyway** only if you trust the download.

### Updating from Beta 6

1. Open **Settings -> Updates**.
2. Keep the update channel set to **Testing**.
3. Check for updates, download Beta 7, and restart when the update is ready.

The release includes:

- `beta.yml` for Testing-channel update discovery.
- An installer blockmap for differential updates.
- `SHA256SUMS.txt` for installer verification.

To verify the installer in PowerShell:

```powershell
Get-FileHash .\MyAI-Library-Setup-0.1.0-beta.7-x64.exe -Algorithm SHA256
```

Compare the result with the installer entry in `SHA256SUMS.txt`.

## System requirements

- Windows 10 or Windows 11
- 64-bit x64 processor
- Internet access for authentication, configured cloud AI providers, model downloads, and application updates
- Additional disk space and memory when using optional local AI models
