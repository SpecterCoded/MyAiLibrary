# My AI Library 0.1.0 Beta 1

This is the first public Windows beta of My AI Library. It is an intentionally unsigned prerelease for early testing and feedback before the first signed Stable release.

## What My AI Library does

My AI Library brings local learning and research material into one desktop workspace. Import videos, audio, PDFs, documents, notes, and other resources; let the local backend process and index them; then search, study, play, and ask questions without losing the connection to the original source.

## Library and import workflows

- Organize local media, documents, notes, and research resources in a unified library.
- Import and process resources in the background with visible queue and progress states.
- Extract transcripts and metadata from video and audio using pinned, packaged FFmpeg tools.
- Track processing outcomes and recover cleanly from interrupted desktop/backend work.
- Navigate folders, resources, recent work, and open tabs using the refined edge-to-edge desktop shell.

## AI, retrieval, and source-aware answers

- Ask questions in Chat or resource-level Ask AI views and receive source-aware streamed answers.
- Follow formatted citations and clickable timestamp badges back to the exact source and media position.
- Open cited video or audio in the side panel without losing the current conversation.
- Use improved rich-text rendering across Chat, Ask AI, generated notes, and media workflows.
- Benefit from batched embeddings, cache invalidation, parent-child retrieval, hierarchical retrieval, HyDE queries, query routing, overlap-aware chunks, ranking, and retrieval evaluation.
- Use the included RAG evaluation and self-test tooling to detect quality regressions.
- See clearer recovery behavior when an AI stream, provider, or backend operation is interrupted.

## Video, audio, chapters, and study tools

- Play complete video and audio resources with captions, seeking, volume, speed, and familiar media controls.
- Browse chapter and subchapter timelines, starred moments, attachments, and media metrics.
- Jump between a transcript, chapter, generated answer, citation, and exact media timestamp.
- Generate summaries, transcripts, flashcards, quizzes, mind maps, notes, Active Recall prompts, and Self-Test material.
- Render timestamp ranges consistently inside generated content instead of exposing raw formatting tokens.
- Use polished player controls and compact tabs that remain responsive in narrow and detached windows.

## Desktop workspace and detachable windows

- Detach supported workspace pages into their own Electron windows and attach them back to the main window.
- Keep custom title bars, tab-aware navigation, and responsive layouts in both main and detached windows.
- Move supported floating tools and preserve practical minimum window sizes.
- Use refined menus, settings interactions, carousel spacing, chat composer expansion, and authentication layouts.
- Avoid title-bar overlap, tab flicker, clipped controls, and narrow-window wrapping regressions addressed during the beta cycle.

## Diagnostics, reliability, and privacy

- Inspect structured diagnostic events across the desktop shell, renderer, backend, queue, AI generation, and RAG pipeline.
- Filter, clear, and export sanitized logs with bounded retention and correlation IDs.
- Open updater logs directly from Settings when diagnosing release checks.
- Keep secrets and sensitive fields redacted from structured diagnostic output.
- Preserve the local-first application architecture and never embed GitHub credentials in the installed app.

## Settings and integrations

- Configure appearance, AI providers and models, storage, diagnostics, integrations, and update behavior.
- Use the bundled `Journalit-Local-1.8.1-Fresh.zip` package from Settings → Integrations, together with the included Obsidian installation guidance.
- Open the packaged Journalit integration folder directly from the application.

## Beta updates and safeguards

- This beta-capable package defaults to **Testing** only when no update preference has been saved.
- Explicit Stable and Testing choices are preserved across launches and future upgrades.
- Settings → Updates supports manual checks, update availability, download progress, restart/install states, and successful-update confirmation.
- Future versions newer than `0.1.0-beta.1` can be delivered from public GitHub prereleases through the Testing channel.
- Stable updates remain signed-only and disabled until a Windows code-signing certificate is available.
- Before installation, the desktop updater prepares a backup, checks database integrity, tracks the pending version, and preserves recovery paths if migration or startup fails.

## Branding

- The application and tray icons use a full-canvas blue gradient with a centered white sparkle mark enlarged to approximately 84% of the source icon area.
- Windows executable, installer, and uninstaller ICO files include frames through Windows' 256×256 maximum.
- Tray PNG and ICO artwork includes frames from 16×16 through 256×256 with tray-specific corner treatment and matching sparkle proportions.
- Windows controls the physical notification-area slot; the artwork fills the maximum usable icon canvas.

## Installation

1. Download `MyAI-Library-Setup-0.1.0-beta.1-x64.exe` from this GitHub prerelease.
2. Optionally verify it against `SHA256SUMS.txt`.
3. Run the installer and choose the installation folder.
4. Windows SmartScreen may show **Unknown Publisher** because this beta is intentionally unsigned. Continue only when the installer came from the official `SpecterCoded/MyAiLibrary` repository.
5. Launch My AI Library from the installer, Start menu, or desktop shortcut.

The per-user installer does not delete application data during upgrade or uninstall by default.

## Verify the download

Run:

```powershell
Get-FileHash .\MyAI-Library-Setup-0.1.0-beta.1-x64.exe -Algorithm SHA256
```

Compare the result with the installer entry in `SHA256SUMS.txt`.
