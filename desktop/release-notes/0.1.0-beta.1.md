# My AI Library 0.1.0 Beta 1

This is the first public beta of the My AI Library Windows desktop application. It is intended for early testing and feedback before the first stable release.

## Highlights

- Organize local videos, audio, documents, notes, and research material in one private AI-powered library.
- Ask questions about imported content with source-aware answers, formatted citations, and clickable timestamp badges.
- Open cited media directly in the side panel and jump to the exact referenced moment.
- Generate structured notes for video and audio, including correctly rendered timestamps in Active Recall & Self-Test answers.
- Use the redesigned desktop workspace, authentication flow, custom title bar, installer branding, and settings experience.

## AI answers, citations, and timestamps

- Standardized rich-text rendering across Chat, Ask AI, generated notes, and media workflows.
- Converted raw timestamp syntax into consistent timestamp badges instead of exposing formatting tokens.
- Added clickable chat timestamps that open the cited video or audio in the left panel at the exact starting time.
- Improved citation rendering and preserved the existing citation side-panel workflow.
- Added prompt-level formatting guidance so newly generated answers follow the supported citation and timestamp format.

## Video, audio, and generated notes

- Improved transcript-based answers and note generation for video and audio.
- Fixed timestamp rendering inside **Active Recall & Self-Test** answer containers.
- Preserved timestamp ranges and source context while keeping the interface readable.
- Improved whole-video and whole-audio playback integration with AI-generated content.

## Journalit trading journal integration

- Bundled `Journalit-Local-1.8.1-Fresh.zip` with the Windows installation.
- The archive is installed under:

  `resources\integrations\journalit\Journalit-Local-1.8.1-Fresh.zip`

- Added an **Open** action in **Settings → Integrations** that opens the bundled Journalit folder.
- Added installation guidance for extracting the Journalit plugin into an Obsidian vault’s `.obsidian\plugins` directory.
- Included the Journalit integration user guide in the application workflow.

## Desktop and interface improvements

- Moved the minimize, maximize, and close controls into a dedicated title-bar row above the login page.
- Prevented native window controls from overlapping login artwork and content.
- Improved workspace and carousel spacing beneath the desktop title bar.
- Refined desktop branding and enlarged the white sparkle mark within the blue executable and installer icon.

## Beta updates

- Added an opt-in **Testing** update channel for unsigned GitHub prereleases.
- Added update checks, availability notifications, download progress, restart prompts, and post-update status.
- Added versioned Markdown release notes for update review.
- Preserved the signed-only policy for future stable releases.
- Added pre-update backup, database integrity checking, migration recovery, and restoration safeguards.

## Installation

1. Download `MyAI-Library-Setup-0.1.0-beta.1-x64.exe`.
2. Run the installer and choose the installation folder.
3. Windows SmartScreen may warn that the beta is from an unknown publisher because this prerelease is intentionally unsigned. Review the publisher information and continue only if you downloaded it from the official My AI Library GitHub repository.
4. Launch My AI Library from the installer, Start menu, or desktop shortcut.

## Verify the download

The release includes `SHA256SUMS.txt`. You can verify the installer in PowerShell:

```powershell
Get-FileHash .\MyAI-Library-Setup-0.1.0-beta.1-x64.exe -Algorithm SHA256
```

Compare the result with the value in `SHA256SUMS.txt`.
