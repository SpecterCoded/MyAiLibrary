# MyAiLibrary — Windows Beta

Turn your videos, audio, documents, PDFs, notes, and research materials into an organized, searchable learning workspace.

MyAiLibrary combines media playback, AI-powered search, study tools, source-aware answers, and local resource management inside one desktop application.

## What you can do

### Build your personal knowledge library

- Import videos, audio, PDFs, documents, notes, and research files.
- Organize resources into folders and playlists.
- Process multiple resources in the background.
- Track imports, processing progress, and recent activity.

### Ask questions about your content

- Chat with your entire library or ask questions about a specific resource.
- Receive source-aware answers with citations.
- Click timestamps to jump directly to the relevant moment in a video or audio file.
- Open cited media without losing your current conversation.

### Study and understand faster

Generate summaries, chapters and subchapters, transcripts, flashcards, quizzes, mind maps, notes, Active Recall exercises, and Self-Test questions directly from your content.

### Watch and listen with context

- Use complete video and audio playback controls.
- Browse searchable transcripts, captions, and chapter timelines.
- Save starred moments and review attachments and media metrics.
- Navigate directly between generated answers and the original media.

### Work your way

- Detach supported pages into separate desktop windows and attach them again.
- Keep multiple resources open using workspace tabs.
- Choose light, dark, or system appearance.
- Configure AI providers, models, storage locations, and integrations.

### Local-first desktop experience

Your library, processing data, logs, and application settings remain under your control on your computer. External AI services are used only when you configure them.

Persistent authentication refresh tokens are encrypted using Windows-protected Electron storage rather than being kept in browser storage.

## Beta notice

This is a public Windows beta intended for testing and early feedback.

The installer is currently unsigned, so Windows SmartScreen may display an **Unknown Publisher** warning. Windows code signing will be added in a future release.

Before testing beta software, we recommend keeping a backup of important or irreplaceable files.

## System requirements

- Windows 10 or Windows 11
- 64-bit processor
- Internet access may be required for configured AI providers and application updates

## Installation

1. Download `MyAI-Library-Setup-0.1.0-beta.3-x64.exe`.
2. Run the installer.
3. If Windows SmartScreen appears, review the warning and choose **Run anyway** if you trust the download.
4. Launch MyAiLibrary and complete the initial setup.

The release also includes `beta.yml` for application updates, an installer blockmap for differential updates, and `SHA256SUMS.txt` for download verification.

## Feedback

MyAiLibrary is actively evolving. If you encounter a problem or have a feature suggestion, please use the bug-reporting link on the project website or open a GitHub issue with clear reproduction steps.
