Is MyAiLibrary free?+
The app is free to download. AI features run through your own API key (added once in Settings), so you only pay your AI provider for what you actually use.
Does it work offline?+
No — an internet connection is required. Your library lives on your machine, but the AI features call an API using the key you configure in Settings.
Which file types can I add?+
Video, audio, PDF and document files — they're all embedded into the same vector database and become searchable together.
Windows warns about an "unknown publisher" — is that safe?+
That's SmartScreen being cautious about independent apps that aren't code-signed by a big company. Click "More info" → "Run anyway". You can inspect the full source code on GitHub before running anything.
Where is my data stored?+
Your library and its vector database are stored completely locally on your machine. Only the AI requests go out — through your own API key.
How do I report a bug or request a feature?+
Open an issue on the GitHub repository, or reach out on Telegram — links are in the footer.
